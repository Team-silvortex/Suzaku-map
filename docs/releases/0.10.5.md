# 0.10.5 Panel interaction reliability

Suzaku Map **0.10.5 / build 55** collects the recent panel, handwriting,
candidate and settings reliability fixes.

This is a **source-only update** for commit and push. It creates no tag,
GitHub Release or installation package and restores no automation. The verified
[0.10.2 Linux Alpha download](https://github.com/Team-silvortex/Suzaku-map/releases/tag/v0.10.2)
remains the installation baseline.

## Fixes

- Successful tool acknowledgements show insertion success only when their source
  is still current; an older success cannot label a newer retained draft as sent.
  Commands that hand off into editing (dictation `I` and the keyboard-tab fallback
  `1`) retain their consumed key until release. A focused compact orb does not
  edit its hidden draft.
- Handwriting tracks the first contact by device and touch ID, ignoring other
  contacts and overlapping emulated mouse events. Focus loss finishes retained
  ink instead of stranding it. Padding stays within each sampling axis to avoid
  reversed clamp bounds; smoothing weights stay within `[0, 1]`.
- Report views retain keyboard ownership across their own mode transitions and
  distinguish equal touch IDs from different devices. Normal paging repeats and
  Escape's matching-release close remain available.
- The independent panel keeps all six local candidates reachable: a selected
  fifth or sixth candidate appears in the fourth sentence-card slot. Enter
  requires the selected or default candidate to have an actual visible target;
  hidden translation-mode cards cannot silently send another candidate.
- Model-provider reconfiguration belongs to the main window, not the auxiliary
  Settings window. Settings focus loss ends scrollbar dragging without resetting
  its position. In the same Settings window, releasing Ctrl before the held
  `Ctrl+,` or `Ctrl+F` command key no longer leaks a repeat into search; fresh
  plain presses and repeats still type normally.
- Complete occlusion retires held pointer gestures. Main and report windows
  reject covered pointer input even after a redraw. Lifecycle, keyboard and IME
  policies are unchanged; this is not a promise to disable every hidden input.

Cross-window transfer of shortcut-key ownership is not added. Existing detached
native recovery remains one in-memory copy for explicit restoration, not a
persistent history or automatic replay into another field.

## Compatibility and validation

Authored vocabulary, all 25 offline packs, their SDK, prediction v1, model budgets
and dependencies are unchanged. No configuration migration is introduced.

Versioned local results and their exact scopes are recorded in the
[0.10.5 validation history](../history/2026-11/release-0.10.5.md). Local checks do
not establish the pushed commit's remote CI result. Private X11 events, synthetic
acknowledgements and controlled focus/occlusion sequences are not physical-input,
personal IBus, real window-manager, real-model or cross-platform runtime acceptance.
This update does not replace the personal installation or change its services
and configuration.
