# 0.10.1 Interface localization and report usability

Suzaku Map **0.10.1 / build 51** improves the eight-language interface, error
feedback and read-only report viewing. Input algorithms, vocabulary, model
protocols and personal configuration formats remain unchanged.

This is a **source-preparation record, not a publication receipt**. The
selected Linux package release requires all eight checks on the exact commit
and independent acceptance of that run's packages. Until publication completes,
the verified [0.10.0 Linux Alpha download](https://github.com/chiharu-kiryu/Suzaku-map/releases/tag/v0.10.0)
remains the installation baseline. No cancelled automation is restored.

The prior complete local run stopped on a synthetic unavailable-model state
assertion. One exact rerun passed, but that is not a fix or complete acceptance;
the original assertion and two-second deadline remain unchanged. The fresh
versioned suite and remote gates must pass independently. See the
[release validation record](../history/2026-11/release-0.10.1.md).

## Interface and diagnostics

- Candidate style badges and tool headers follow the selected interface
  language. Long translated labels use measured font widths and stay inside
  bounded windows.
- Model checks, activation, recovery, preference clearing and data-operation
  messages translate their known outer text, preserving paths, provider names,
  status codes and unknown diagnostics. Changing the interface language does
  not repeat an operation or reinterpret an external parameter.
- Input-method errors appear in the focused settings window when applicable;
  otherwise the main panel opens as needed, including from the compact bubble.
  Feedback follows the three text sizes without dropping short trailing words.

## Read-only report details

The tray can open current input-method errors and the last data-operation
result. Details support buttons, scrolling, PageUp / PageDown and Escape;
closing returns to the previous settings navigation without rolling back newer
preferences. Viewing does not repeat the operation, show or unfold the main
panel, edit drafts, copy text or write report files.

Reports use reversible visible escapes and paginated text, with an explicit
bounded-preview notice above the **2 MiB display limit**. Small windows keep
the selected text size, required notice, visible body and close controls.
Reflow retains the reading anchor; only successfully presented controls accept
matching complete gestures. The settings-scroll reset found in private UI
testing is fixed without relaxing its original assertion.

## Compatibility and verification

The interface supports English, Simplified Chinese, Japanese, Korean, Spanish,
French, German and Portuguese through **419 static resources**. Input-language
and translation-language selection remain independent. All 25 recommended
offline packs and the SDK retain their original contents.

The package target remains **Ubuntu 24.04 amd64 / glibc 2.39 / IBus / X11 or
GNOME/XWayland**, as a Linux Alpha prerelease, not latest stable. Windows and
macOS compile checks do not establish equivalent native support. No models or
user input data are bundled, and publication does not replace the personal
installation or operate its input-method services.
