# 0.9.5 Kitchen and bedtime fallback

Suzaku Map 0.9.5 prepares two finite everyday-vocabulary batches: kitchen
coordination and bedding/bedtime preparation. It remains a **Linux / IBus
Alpha**, targeting **Ubuntu 24.04 amd64, glibc 2.39, X11 or GNOME/XWayland**.
Synchronized version metadata does not establish native support on other
platforms.

**Source preparation: 0.9.5 / build 45.** The independent versioned full Rust
run passes **2,623 tests / zero failures / 32 existing explicit ignores**,
across **275 unfiltered result groups including Doc-tests**. The new **19 exact
isolated UI gates** and strict all-target/all-feature Clippy (**1m03s**) also pass. Exact-commit
remote CI and accepted-package validation must follow independently. There
is no published 0.9.5 tag, release, download or installation receipt yet.
Preparing this version does not restart the cancelled publication automation
or change the personal installation and input-method services/configuration.

## Everyday offline fallback

Compared with the **0.9.4 source baseline** `d2b0a1a` (not a claim that 0.9.4
packages were published), this version adds:

- English: **14 builtin indexed forms, 10 contexts and 20 authored sentences**,
  across two additional ordered layers.
- Simplified Chinese: **20 Word readings, 10 contexts and 20 authored sentences**.
- Japanese: **eight Word readings, 10 contexts and 20 authored continuations**.

That is **28 CJK Word readings, 14 English forms, 30 contexts and 60 trilingual
authored sentences**. Totals are **6,193 English forms / 867 contexts / 1,698
sentences (55 layers)**, **3,410 Chinese readings / 861 contexts / 1,720
sentences**, and **622 Japanese readings / 349 contexts / 697 continuations**.

The kitchen batch adds English `bowls`, `spoons`, `forks`, `apron`, `cutting`,
`rack`, `tray` and `lids`; Chinese phrases such as “我先把菜洗好”, “盘子再拿两个”
and “吃完我来收桌子”, plus 菜板, 锅铲, 盘子, 碟子, 饭碗 and 筷架; and Japanese
スプーン, フライ返し, 穴あきお玉, エプロン and 水切りかご. The existing 箸 Word
gains its own continuations, not another duplicate reading. `bowls` and
`spoons` already existed in the optional English cooking pack: the counts
above describe builtin growth, not first appearance in every catalog.

The bedding batch adds English `sheet`, `sheets`, `pillows`, `bedside`,
`slippers` and `pajamas`; Chinese 枕头, 被子, 毯子, 床垫 and four everyday
phrases, including “床单换好了吗” and “睡前把床铺好”; and Japanese シーツ, 毛布
and パジャマ. The existing 目覚まし Word gains authored continuations without
being counted again. Existing 床单, 被套, 枕套 and family-pack 床单收纳 remain.

These are authored input expressions, not recipes, medical or sleep-effect
advice, alarm scheduling, device control or open-ended generation. New
explicit Words do not imply their characters were previously impossible
to type. This release adds no third-party corpus, personal input history
or bundled model.

Local candidates remain independent of optional models when prediction is
disabled, missing, pending, failed, timed out or empty. The provider-neutral
model contract and runtime conversion/ranking logic are unchanged. No model
is automatically downloaded or made a new hard dependency.

## Compatibility and limits

The original resources, reading flags/order and first 6,179 English occurrence
ranks are retained. All **25 recommended data-only packs** (eight English,
eight Chinese and nine Japanese) and the SDK are unchanged. Startup-only
catalog loading, 16 installed-pack slots, per-source/per-pack work budgets,
the six-row page size and default twelve-row candidate list remain unchanged.
This release does not introduce new conversion or sentence-slot algorithms.

New whole Words and authored contexts can still change short-prefix pools,
scores or pages under the same bounded algorithm. For example, the reviewed
nine-pack `fur` kitchen pool retains フライパン but loses its two older
authored candidate rows while containing eleven rows; that is not a final
twelve-row truncation or deletion of source authors. In the bedding samples,
the twelve-row `mou` pool can replace a generated tail Word, builtinも受付 or
nine-packも受け取り. Original source Words and authors remain, but not every
short-root generated choice is guaranteed to stay selectable.

Romanization is still finite: `supu-n` and `shi-tsu` use explicit long marks;
this does not add arbitrary long-vowel aliases, a full Japanese morphology
dictionary or arbitrary Katakana-to-Kanji reverse lookup. Specific tested
partials are not promises about all shorter prefixes. Existing small-limit
boundaries are not expanded. Passing the existing isolated UI gates does not
establish physical-keyboard/native-desktop, real-model quality, cold-start,
latency or personal-installation acceptance from these data additions.

## Install or upgrade only after publication

The four expected assets are:

- `suzaku-0.9.5-x86_64-unknown-linux-gnu.tar.gz`
- `suzaku-0.9.5-x86_64-unknown-linux-gnu.tar.gz.sha256`
- `suzaku_0.9.5_amd64.deb`
- `suzaku_0.9.5_amd64.deb.sha256`

Use only accepted assets after the 0.9.5 prerelease has actually appeared.
Finish or cancel the current input draft and fully quit both host and panel
before upgrading:

```bash
sha256sum -c suzaku_0.9.5_amd64.deb.sha256
sudo apt install ./suzaku_0.9.5_amd64.deb
/usr/bin/suzaku-panel
```

For a first installation, register as the desktop user **without sudo** with
`/usr/bin/suzaku-tool linux-register install`, then
`/usr/bin/suzaku-tool linux-register verify`. Activation remains an explicit
tray action. Restart host and panel together after upgrading; settings and
pack registrations are retained. Archive users must verify the external
checksum and internal `SHA256SUMS` before running `./bin/panel`.
See [Linux packaging and data](../linux-packaging-data.md) and
[known limitations](../known-limitations.md).
