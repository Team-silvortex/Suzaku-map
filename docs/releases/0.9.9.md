# 0.9.9 Source update — daily and workplace dialogue

Suzaku Map 0.9.9 / build 49 extends authored English, Simplified Chinese and
basic Japanese offline fallback. This is a **source-only commit and push**;
no tag, GitHub Release or installer publication is requested. The verified
[0.9.7 Linux Alpha download](https://github.com/chiharu-kiryu/Suzaku-map/releases/tag/v0.9.7)
remains the installation baseline. No personal installation, input-method
service/configuration or cancelled automation is changed.

## Preserved contracts and explicit short-input changes

Input algorithms, base weights, model/provider protocols, reading arrays and
their order remain unchanged. All 25 recommended data-only packs (8 English /
8 Chinese / 9 Japanese) and the offline-pack SDK remain byte-identical.
Candidate capacity, six-row paging, startup discovery and work budgets do not
change. No model or personal input history is bundled.

Five twelve-case integration fixtures add 60 Rust tests; two independent
compatibility fixtures add four more. They exercise fixed word/sentence
choices, near-complete readings, tones and Kana, raw rescue, line/token
boundaries, adoption/undo, long drafts, single commits, private optional-pack
coexistence and synthetic unavailable-model cases. Exact test-only resource
inverses preserve complete historical source contracts.

New authored data can legitimately change short-input candidate pools. The
farewell batch adds one Word to the English `i s` vector; the Japanese work
batch changes `henk` in builtin and fixed nine-pack modes. For the latter,
180 of 182 ordered A/B records remain identical. Two new change-history
sentences enter the first page; old return-deadline sentences move to the
second page with changed position scores. Older `返却` / `返金` tail Words
are evicted from that twelve-slot short-input pool; complete spellings remain
selectable. Strict test-only adapters first assert every field of each exact
new vector, then reconstruct the complete measured historical vector. Old
corpora, goldens, production limits and runtime logic are not rewritten.

Chinese `xu'qi` retains the older `续期` Word alongside `需求`. Japanese
`担当` can also prefix the optional work-pack Word `担当者`; no continuation
is invented for that older Word. Broad kana `かい` is not a first-page
promise for the new meeting sentences; complete `かいぎ` is the positive
kana input. Japanese remains finite Romaji/Kana fallback, not arbitrary
long-sentence conversion or a full morphological analyzer.

The initial workplace preflight really failed (180 passes / 4 failures across
25 complete targets). Its raw evidence is retained. Complete A/B inspection
established the exact `henk` data change; a separate 26-target preflight then
passed 186 checks. These development results, private children and prior
bounded runs are not counted as the new version's complete validation.
