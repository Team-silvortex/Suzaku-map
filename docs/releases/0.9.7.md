# 0.9.7 Everyday dialogue fallback

Suzaku Map 0.9.7 expands authored English, Chinese and Japanese offline
fallback. It remains a **Linux / IBus Alpha**, targeting **Ubuntu 24.04 amd64,
glibc 2.39, X11 or GNOME/XWayland**. Other platform version metadata does not
establish equivalent native support.

**Source preparation: 0.9.7 / build 47.** The independent versioned full Rust
run passes **2,805 tests / zero failures / 32 original ignores**, in **301
unfiltered groups including Doc-tests**. Separately, **19 isolated UI gates**
and strict all-target/all-feature locked-offline Clippy with warnings denied
pass (61.25s main process). Exact-commit remote CI and accepted-package
validation remain **pending**. Earlier bounded development runs are historical,
not substitutes for this complete 0.9.7 run.
No tag, published Release or download is claimed here. The cancelled automation
remains cancelled; this release does not change the personal installation or
input-method services/configuration.

## Preserved contracts

Production input algorithms and model/provider protocols are unchanged from
0.9.6. The Chinese and English Rust source changes only maintain current
test totals; the production compatibility repairs listed in the 0.9.6 release
are already in the baseline, not new 0.9.7 work.

All **25 data-only recommended packs** (8 English / 8 Chinese / 9 Japanese)
and the offline-pack SDK remain byte-identical. Startup discovery, sixteen
installed-pack slots, work budgets, six-row page size and the default
twelve-row candidate capacity do not change. No model is required or downloaded.

Regression coverage includes words and authored sentences, selected partials,
Pinyin tones, fixed Kana and terminal `n`/`nn`, case, horizontal gaps, seven
line boundaries, opaque tokens, raw rescue, adoption/reseed, long prefixes,
explicit single commit/undo and private optional-pack coexistence. Synthetic
missing, pending, disabled, failed, timed-out and empty providers check local
fallback, not real-model quality.

Old raw-resource inverses, historical windows and reviewed replay goldens are
retained. The new Chinese 遥控器 Word explicitly changes the reading inventory;
new authors and three English forms can change short-prefix pools and scores.
Old 6,213 English first-seen ranks remain frozen; all 6,216 ranks are not
claimed invariant. Earlier rejected sock and 理解 author contexts and a
conflicting `let me know when you are` context remain documented as failed
development attempts, not shipped data. See the [development record](../../DEVELOPMENT.md)
and [lexicon history](../../data/lexicons/README.md).

### Two release-preparation data corrections

The first complete versioned candidate failed two historical Chinese
compatibility tests: **2,799 passed / 2 failed / 32 original ignores**, in 300
unfiltered groups. A separate four-case red specification then checked all
eight old restock inputs without stopping at the first mismatch and exposed
a second affected input that those tests had not reached.

Only two unshipped authored contexts and their four sentences were replaced:
`收纳袋` becomes existing Word `耳塞`, and `卡住` becomes existing Word
`未完成`. The original 收纳袋 and 卡住 Word readings remain unchanged.
This restores the sampled `shou na` and `ni de hua mian ka zhu le` pools and
avoids a malformed suffix-spliced video-call sentence. Word/readings, total
contexts/sentences, production algorithms, budgets and old candidate oracles
are not changed by these corrections.

A test-only exact inverse binds both reviewed slots and the complete original
readings byte prefix before invoking the unchanged historical resource hashes;
it never projects or alters runtime candidates. Four added regression cases
check the six-string delta, all eight old vectors, explicit commit/undo of the
new suggestions, and strict inverse boundaries. The focused repaired run
passes 65 tests / zero failures across ten groups; it is not included in the
independent final complete-run total. Both failed-source snapshots and their
logs remain preserved. The independent final full run passes 2,805 tests with zero failures and
32 original ignores across 301 unfiltered groups. Separately, 19 isolated UI
gates and strict Clippy pass; neither is added to the full-run total. These
local results do not replace exact-commit CI or accepted-package validation.
