# 0.8.9 Broader offline packs and safer continuous editing

Suzaku Map 0.8.9 expands the model-independent fallback vocabulary, organizes
optional language/topic packs and fixes standalone adoption/undo boundaries.
It remains a **Linux / IBus Alpha**, targeting Ubuntu 24.04 amd64 with X11 or
GNOME/XWayland. Keep another input method available. Shared version metadata
does not qualify native behavior on other platforms.

This version follows the 0.8.8 source work. At preparation time, 0.8.8 had not
been tagged or published with packages; the last downloadable release was 0.8.7.
Upgrading from 0.8.7 also includes the default-on, clearable local candidate
preference persistence described in the [0.8.8 notes](0.8.8.md). Those historical
CI runs and package results do not qualify this new commit.

## Everyday fallback, separate from the model

Compared with the 0.8.8 source baseline (`e416e86`), built-in authored resources add:

- English: **32 contexts and 64 sentences**, reusing existing indexed forms.
- Simplified Chinese: **96 readings, 32 contexts and 64 sentences**.
- Japanese: **36 readings, 18 contexts and 36 continuations**.

The additions cover receiving visitors, collecting deliveries, describing
household repairs, laundry/clothing and Japanese mealtime expressions.
Current totals are **6,143 English indexed forms / 741 contexts / 1,446 sentences**,
**3,066 Chinese readings / 735 contexts / 1,468 sentences**, and
**402 Japanese readings / 202 contexts / 403 continuation records**.
These are record counts, not a general dictionary-quality score.

Earlier ranks, authored ordering and candidate/index budgets remain protected.
Local word/sentence choices remain available when a model is off, missing,
empty or failing. No downloaded corpus, personal-history corpus or model is
bundled; authored fallback is not open-ended generation.

## Twenty-five optional language/topic packs

The catalog grows from **14 to 25 packs: 8 English, 8 Chinese and 9 Japanese**.
Shopping and internet are added for English/Chinese; Japanese gains internet,
shopping, travel/lodging, work, study, cooking and astronomy collections.
The eleven new packs declare 112 English forms, 80 Chinese readings, 240 Japanese
readings and 312 sentences; these are declared records, not deduplicated net words.
All packs remain project-authored MIT-licensed JSON at pack version `1.0.0`.

The catalog is not an installation quota: **at most 16 packs may be installed,
including disabled packs**. Catalog inclusion does not install or enable packs;
explicitly installing a new pack enables it. Select by language and topic, then
restart the host/panel to load registration changes. Per-pack,
per-language and candidate budgets are unchanged.

`pack catalog --details` and `pack inspect FILE` expose metadata and declared
counts without consulting the personal pack registry. Pack and SDK READMEs are
shipped alongside the JSON resources. The small Python SDK now rejects a string
where a word collection is required, accepts tuples/generators, preserves author
order and retains authoritative Rust validation and no-overwrite output rules.
These are data packs, not executable plugins or automatic downloads.

See the [catalog](../../data/offline-packs/README.md) and
[SDK guide](../../sdk/offline-packs/README.md).

## More predictable Japanese and panel editing

Japanese finite preset continuations better retain incomplete Romaji tails,
conservatively probe a single unfinished `n`, and avoid joining split syllables
across separators. `thi` supports `てぃ` without changing `ti → ち` or existing
aliases. Closing punctuation no longer turns authored grammatical `した` tails
into the short noun `下`; original punctuation, literal input and unrelated noun
conversions remain available. Candidate backfill uses existing spare slots, not
larger windows or a complete Japanese morphology engine.

Standalone number choices now share reversible adoption history with word chips,
including Chinese/Japanese choices without English next-word chips. Invalid,
unchanged or stale-source choices do not destroy history. Confirmed configuration
changes clear obsolete local adoption history even while it is suspended behind
a native view; ordinary view switches and unchanged/shortcut-only settings retain it.

A held Back click is bound to its original history revision, draft and language.
It cannot undo a later adoption after repaint, revive after undo/reapply to the
same text, or survive a native-view roundtrip. New gestures and unchanged-history
refreshes remain usable. Space continuity, exact explicit commits, native host
adoption and the 32-edit local bound retain their existing meanings.

## Validation and publication boundary

Development evidence is recorded in [DEVELOPMENT.md](../../DEVELOPMENT.md).
The new pack regressions cover individual languages and nine bounded 16-pack
combinations whose union includes all 25 catalog entries. Existing GTK/native
pack-specific workflows still use the historical fourteen-pack fixture; they
do not establish physical-input acceptance for every new pack. Panel gesture
tests use private displays and synthetic events, not the user's desktop.

Local validation on the versioned source passes 2,034 Rust tests (32 explicitly
ignored in that invocation), the separate complete 19-test private UI gate,
strict all-feature/all-target Clippy, formatting and selected source/pack guards.
These results do not replace remote CI or qualify a downloadable package.

The exact clean release commit must pass **linux, linux-apps, linux-package,
secrets, format, both Windows/macOS desktop checks and linux-artifacts**.
Only the accepted artifact for that same commit/run may supply the `.deb`,
binary `.tar.gz` and their two SHA-256 files. Package manifests, checksums and
clean Ubuntu 24.04 installation/upgrade/removal checks are required. A source
commit, tag, local test result or unaccepted staging artifact is not publication.

Cargo version is **0.8.9**; Android/macOS build number is **39**. Dependency
versions and optional-pack versions are unchanged. Native Wayland, physical
device ergonomics, real-model quality/latency, complete Japanese analysis and
non-Linux native behavior remain outside this release's acceptance. See
[known limitations](../known-limitations.md).

## Install or upgrade after publication

Use matching assets from the [0.8.9 Release](https://github.com/chiharu-kiryu/Suzaku-map/releases/tag/v0.8.9)
only after all gates pass and the assets are published. Finish/cancel the draft
and fully quit Suzaku before upgrading:

```bash
sha256sum -c suzaku_0.8.9_amd64.deb.sha256
sudo apt install ./suzaku_0.8.9_amd64.deb
/usr/bin/suzaku-panel
```

On first installation, register as the desktop user, **without sudo**:
`/usr/bin/suzaku-tool linux-register install`, followed by
`/usr/bin/suzaku-tool linux-register verify`. Installation does not activate the
input method. Tray activation/restoration remains explicit; restart host and
panel together after an upgrade. Settings and pack registrations are retained.
Publication does not replace an existing daily installation.

The archive alternative is `suzaku-0.8.9-x86_64-unknown-linux-gnu.tar.gz`, with its
`.sha256` and internal `SHA256SUMS`. Verify them before running `./bin/panel`.
It is not a universal static binary; checksums provide integrity, not signatures.
See [Linux packaging and data](../linux-packaging-data.md).
