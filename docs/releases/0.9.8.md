# 0.9.8 Source update — everyday dialogue

Suzaku Map 0.9.8 / build 48 extends authored English, Simplified Chinese and
basic Japanese offline fallback. This is a **source-only commit and push**;
no tag, GitHub Release or installer publication is requested. The verified
[0.9.7 Linux Alpha download](https://github.com/chiharu-kiryu/Suzaku-map/releases/tag/v0.9.7)
remains the installation baseline. No personal installation, input-method
service/configuration or cancelled automation is changed.

## Five everyday dialogue batches

Compared with published 0.9.7 source
`354030b1107b20ad2447a9f93aaa6cf6beba1c40`, each batch adds three contexts
and six authored sentences per language:

| Batch | English contexts | Chinese contexts | Japanese contexts | Combined sentences |
| --- | ---: | ---: | ---: | ---: |
| Stepping away and returning | 3 | 3 | 3 | 18 |
| Turn-taking and offering help | 3 | 3 | 3 | 18 |
| Rephrasing and uncertainty | 3 | 3 | 3 | 18 |
| Alternatives, preferences and choices | 3 | 3 | 3 | 18 |
| Temporary changes and rescheduling | 3 | 3 | 3 | 18 |
| Total | 15 | 15 | 15 | 90 |

Combined growth is **45 contexts / 90 authored sentences**, with no new
English forms or Chinese/Japanese readings. English gains one empty-words
64th layer; subsequent batches extend that layer without increasing the
64-layer budget. All 6,216 English first-seen ranks remain exact.

Current builtin totals:

- English: **6,216 indexed forms / 930 contexts / 1,824 sentences, 64 layers**.
- Simplified Chinese: **3,442 readings / 921 contexts / 1,840 sentences**.
- Japanese: **638 readings / 409 contexts / 817 continuations**.

Examples include “临时有安排，我们能换个时间吗？”, Japanese
“日程が変わったら、早めに連絡します。” and English
“something came up, could we meet later this week?”. These are finite text
suggestions, not presence detection, fact checking, calendar interaction,
automatic negotiation or rescheduling, message sending or task execution.

## Preserved contracts

Input algorithms, weights, model/provider protocols, reading arrays and their
order remain unchanged. All 25 recommended data-only packs (8 English /
8 Chinese / 9 Japanese) and the offline-pack SDK remain byte-identical.
Candidate capacity, six-row paging, startup discovery and work budgets do not
change. No model or personal input history is bundled.

Five twelve-case integration fixtures add 60 Rust tests. They cover explicit
word/sentence choices, near-complete readings, tones and Kana, raw rescue,
line/opaque-token boundaries, adoption/undo, long drafts, single commits,
private optional-pack coexistence and synthetic unavailable-model cases.
Test-only exact resource inverses preserve historical source contracts; runtime
candidate checks use the expanded resources. Existing hashes, frozen candidate
vectors, assertions and deadlines remain intact. New authored tails can add
choices to other short-prefix pools; universal pool invariance is not claimed.

## Developer artifact retention

The manual local-artifact retention policy and planner are included with 17
synthetic temporary-file tests. The planner defaults to preview, consumes an
explicit inventory and never guesses source identity or executes artifacts.
Apply requires a reviewed plan hash and explicit external inactivity check,
revalidates retained and retired files, takes Cargo profile locks and unlinks
only enumerated unchanged regular files. It is not an automatic scanner,
process detector, recursive cleaner or scheduled job. No cleanup is performed
as part of this source update. See [Contributing](../../CONTRIBUTING.md).
