# 使用指南

先看 [开始使用](getting-started.md)，再按需要查阅下列详细说明。
当前原生验收重点是 Linux / IBus；跨平台代码存在不等于其他平台已完成同等验收。

| 任务 | 说明 |
| --- | --- |
| 安装、升级、数据备份和离线词包 | [Linux 打包与数据管理](../linux-packaging-data.md) |
| 连续输入、选词、分页、提交与偏好缓存 | [IBus 输入与候选](../ibus-candidates.md) |
| 切换语言、自定义组合和设置页键盘操作 | [快捷键](../shortcuts.md) |
| 本地模型发现、服务配置与云端接入 | [模型提供器](../model-providers.md) |
| 显式翻译和目标语言 | [文本翻译](../translation.md) |
| 修改程序界面语言 | [界面多语言](../interface-languages.md) |
| 输入数据、模型请求和本地偏好数据的边界 | [隐私](../privacy.md) |
| 支持范围与故障边界 | [已知限制](../known-limitations.md) |

面板布局在“设置 → 外观 → 面板布局”中选择：自动、跟随光标或底部布局。
底部布局是浮动覆盖层，不会为其他应用保留屏幕空间；定位受窗口系统和应用报告的光标位置限制。
托盘提供显示/隐藏、激活/释放、输入语言及退出入口。

详细指南沿用原文件地址，便于旧书签与安装包继续访问。
过去的回归和安装试验请从 [历史目录](../history/README.md)查找；
查下载和版本变化请看 [版本说明](../releases/README.md)，不要按旧开发日志安装。
