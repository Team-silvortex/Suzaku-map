# 八语界面完善记录

2026-10-28，基于 `9fcd2cd14837f04303d33e5e5ce789332d456bde` 后的工作区。
本轮完善界面文案与长译文排版，不增加输入语言、不更改词库、模型协议或候选排序。

## 候选与模型状态

静态资源从 326 条增加到 349 条：九种候选风格、三种模型检查状态和十一种失败说明。
原 326 条资源的内容与次序保持。资源继续覆盖英语、简体中文、日语、韩语、西班牙语、
法语、德语和葡萄牙语，动态消息限定为单个 `{}` 槽位。

候选元信息与徽标只翻译程序自有的风格标签，正文、草稿和候选索引不变。
徽标按译文宽度扩展；同名的用户文本不会被翻译。
托盘在模型检查边界把状态和有类型的错误转为界面模板，模型名称、服务地址和 HTTP 码原样代入。
完成的报告随语言切换重绘，不重新请求模型；CLI 的原有 summary 与错误 Display 不变。

## 页头与窗口

键盘、语音和手写共用译文测量，并根据可用宽度选择并排或上下布局。
自然高度和正文使用同一份测量结果；浮动与底部窗口的高度估算使用当前字体 atlas 的宽度。
GPU 渲染测试补充八语工具场景，并在实际字体测量下同步计算测试窗口高度。

独立检查还发现受限旧窗口中，新增的页头空间可能把按键或语音状态推到可见区域外。
三个工具正文现把绘制、文字边界及点击范围裁剪到实际抽屉；局部文字如实标记为截断，
完全不可见的控件不保留点击区域。自然高度恢复后显示完整内容，不通过持续缩小字号处理长译文。

第一次统一裁剪使全可见按键的高度出现约 `0.00003` 的浮点差异，触发原有分页严格比较。
修复为保留全可见矩形的原始值，仅对越界部分求交；原测试和新受限视口断言均未放宽。

## 剩余边界

引擎 IPC 的 `prediction_error: String`、输入法生命周期和数据管理的部分失败诊断仍需后续统一；
本轮只处理托盘显式模型检查/预热的错误，不对任意错误字符串或模型输出进行递归翻译。
预热错误沿用“模型检查”措辞，`auto` 预热成功仍显示配置模型名，这是现有展示边界。
System 仍按 `LC_ALL → LC_MESSAGES → LANG` 的第一个非空值解析，未增加 `LANGUAGE` 规则。
手写候选在旧短帧被临时裁剪时尚不额外触发悬停滚动；恢复自然高度后不受此限制。

使用行为见[界面语言](../../interface-languages.md)。本轮不升版、不提交推送、不安装，
不更换日常输入法或修改已发布标签/安装包；功能关联、成熟度评分与运行图保持不变。
