# 错误提示可见性与文字大小

2026-10-28，接续[输入法错误提示的八语显示](interface-diagnostics.md)。
本轮解决错误出现在另一扇窗口、悬浮球吞掉错误及提示不跟随文字大小的问题，
保留草稿、翻译结果、输入法控制和设置持久化流程。

## 显示位置

正在独立设置窗中操作时，输入法错误显示在该窗正文区域的底部，不覆盖关闭按钮、搜索与分类栏，
也不唤出另一扇主窗。其他情况下显示主面板；若主面板处于悬浮球状态，则为错误主动展开，
不受刚折叠时的 180 毫秒防抖限制。普通成功反馈不会因此展开悬浮球或复制到设置窗。
代码不主动请求键盘焦点，不新增 IBus、模型或数据操作。

## 提示排版

主面板、设置页、工具页头和提示共用三档标签字号基准，原界面三档数值不变。
悬停提示仍限制为 340 基准宽、三行；操作反馈改为最多 600 基准宽、六行，
都受实际视口限制。设置反馈使用当前场景的正文边界，不以固定标题高度猜测位置。
短窗口无法在控件上方或下方容纳悬停提示时，不再把提示压到控件上。

布局继续使用当前字体的测量结果。局部反馈区域的形状、字形与裁剪范围统一平移，
首次与后续帧保持一致。错误参数仍保持原文，界面语言只改变程序自有文案。

## 验证

新增独立隔离 UI 测试，覆盖八语、三档文字大小和 420、520、900 宽度。
设置窗有二十四个语言与字号组合，三种宽度配对使用；另在固定 520 宽度比较三档实际字形，
并验证有未聚焦设置窗及无设置窗的十六个主窗回退组合。
它检查设置窗路由、未聚焦设置窗及无设置窗时的主窗回退、刚折叠后的强制错误展开、
实际 X11 焦点保持、原始参数、草稿与设置保真，以及两帧布局和真实渲染。
九个纯测试另覆盖提示预算、字体测量、短视口、非有限尺寸、正文坐标裁剪及完整短文。

保留旧事件处理分支的负对照实际失败：设置窗的反馈为 `None`，
而冻结测试要求 `Input method error: Font: Settings`。这是明确的路由失败，
不是字体或窗口尺寸失败；恢复新路由后使用同一测试，不放宽断言。
负对照日志为 `/tmp/suzaku-feedback-ux.3UgYn1/route-negative-control.log`。

首轮相关回归还保留一项新增夹具失败：测试误把换行当作硬换行，
但通用标签会归一化空白后按词重排，原文本在较宽反馈区自然只占五行。
原文本现保留为少于六行、完整且不截断的对照；更长文本严格检查三行与六行上限及截断，
未为达到测试行数缩小生产宽度或修改公共换行规则。
首轮日志为 `regression-final.log`，独立提示检查为 `hints-focused.log`；它们不累加到最终回归。

修正夹具后的第一轮完整相关 Rust 回归通过 983 项，零失败、25 项显式忽略，十五个结果组且零筛除。
范围为完整 library、panel 单元测试和十三个界面及布局 integration target，不是全仓 Rust。
八个新增纯测试已计入这 983 项；忽略项由原有 24 项与新增隔离 UI 入口一项组成，

随后新 UI 门真实失败，保留在 `ui-private.log` 与补充上下文的 `error-diagnostic.log`：

这个条件下最后字形的排版推进量超过多留的一个像素，末词被挤到下一行，旧高度却只容纳一行。

## 边界

反馈仍是限行的临时提示，不提供全文详情、复制或点击关闭；显示时间继续沿用原有帧计数。
特别长的错误可能省略，数据管理的完整报告入口仍待完善。本轮不新增手势命中区或改变候选采纳。
隔离 UI 不代替真人键盘、真实模型、个人安装或其他平台运行验收。
不升版、不提交推送、不安装，不操作日常输入法服务或个人配置，不恢复定时任务。

当前操作说明见[使用指南](../../users/README.md)。验证日志目录可能随系统清理消失。
