# 操作报告只读分页

2026-10-28，接续[提示可用性](feedback-usability.md)。限行反馈仍作为快速摘要，
输入法错误和上次数据操作增加独立的全文分页入口，普通长度的报告不再受摘要行数限制。

## 查看与关闭

托盘的“输入法错误详情”读取当前错误；数据管理中的“查看上次数据操作”读取上次结果，
即使下一次操作仍在进行也能查看旧结果。两者只发送类型化快照，不重复备份、打开目录、
启动服务或请求模型。查看期间的新结果不覆盖已打开的快照。

详情临时复用设置窗口，支持前后页按钮、滚轮、PageUp / PageDown、方向键及 Home / End。
Esc 配对释放或点击“关闭详情”返回原设置；临时新建的详情窗则直接关闭。
系统窗口关闭按钮仍关闭整扇设置窗口。详情页不接收草稿、搜索、录制或候选编辑，
不自动复制、导出或写入报告。主面板不因查看报告而显示或展开。

原设置的搜索、分类、折叠和滚动位置保留，退出时同步主窗的最新偏好，避免旧值反向回写。
主窗重绘和候选自动隐藏不关闭报告，明确的“隐藏面板”仍关闭辅助窗口。

## 显示边界

新增十一条八语资源，总资源为 419 条；原 408 条及其顺序保持。
固定外层按界面语言显示，原始参数不递归翻译。空格保持，控制字符、零宽字符、引号与反斜杠用可逆转义显示。
正文按字符网格分页，不把原文作为设置搜索、草稿、窗口标题或动作标签。

显示缓存最多 2 MiB，超限明确提示“仅提供有界预览”，原始快照仍在内存中。
每页最多 2048 个字符，只为当前页生成字形；调整窗口时重算边界，不为整份报告创建字形。
重分页按旧页起始字节定位，保留阅读锚点。字体推进量不决定正文分页，字形仍按格裁剪，
不保证任意自定义超宽字体的字形完整。空间不足时收起辅助说明，不缩小所选字号或隐藏超限警告。
仅成功呈现的私有按钮区域可点击，测量、失焦、换页和尺寸变更不会授权陈旧手势。
