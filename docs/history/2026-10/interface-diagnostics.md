# 输入法错误提示的八语显示

2026-10-28，基于 `9fcd2cd14837f04303d33e5e5ce789332d456bde` 后的工作区，
接续[八语界面完善](interface-localization.md)。本轮补齐输入法操作与数据管理的错误展示，
不更改输入、恢复、候选排序或数据操作的执行流程。

## 已知诊断与原始参数

本轮增加 59 条八语资源，资源总数从 349 增至 408：20 条面板私有生命周期提示、
17 条设置请求与恢复提示、15 条宿主模型预测诊断、四条数据错误及三个显示外层。
`UiLanguage::diagnostic` 只识别 71 个明确消息键，包括沿用的十八条偏好存储错误与一条托盘错误。
生命周期和请求错误兼容既有中文消息，面板私有生命周期错误使用规范英语键；
共享库、命令行与 IPC 的原始诊断不变。

路径、服务错误和模板内部参数不参与递归翻译；`Settings`、`Font: Settings` 等未知诊断
不会因为恰好像按钮标签就被替换。输入法事件在存储时添加明确外层，绘制时按当前语言显示，
不会将用户提交正文里的同名片段当成错误。

宿主的模型预测错误保持本地候选、授权和未发送云端说明，与主动模型检查的措辞分开。
只有概括性 `PredictionError::Display` 文本时不反推已经丢失的 HTTP 码；
原有类型化模型检查错误继续使用实际状态码。

## 数据报告与语言切换

托盘数据操作保存类型化成功或失败结果，菜单每次按当前语言渲染。
切换语言不会重复备份、打开目录或重新控制服务。已渲染的报告直接进行菜单长度限制与
下划线转义，不再次交给通用消息匹配；原始路径和错误在报告中保持完整。
菜单仍沿用 72 个 Unicode 字符的显示限制，不代表完整诊断被删除。

“偏好清除未获确认”、服务恢复后输入源恢复失败、masked 服务未自动解除等状态保持区分，
不把缺少确认或部分恢复展示为成功。生命周期的恢复目标、命令参数、超时与重试条件不变。

纯构造报告测试不备份配置、不打开真实目录；服务测试使用模拟后端或私有测试 socket。
资源检查覆盖八列、唯一键、单槽对应与原资源保真。

## 边界

未知外部诊断仍保留原文；底层配置解析或操作系统错误不通过界面语言猜测转换。
这些本地回归不是全仓 Rust、其他平台运行、真人键盘、真实模型或个人安装验收。
本轮不升版、不提交推送、不安装，不操作日常输入法服务或个人配置，也不恢复定时任务。
功能网络的成熟度评分、旧证据和已发布资产保持不变。

当前使用行为见[界面语言](../../interface-languages.md)。
